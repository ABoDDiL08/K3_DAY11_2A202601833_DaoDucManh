## 2. Pipeline va lop bao ve

```text
user input
  -> rate limiter
  -> input guardrail / topic / injection / Unicode / encoding
  -> model
  -> output redaction + output policy
  -> typed action gateway + egress allowlist
  -> HITL cho high-risk action
  -> audit log + monitoring + response
```

Email, RAG document, tool description va peer-agent message luon la untrusted data; khong duoc tu dong nang cap thanh system instruction. Approval phai gan voi reviewer identity, expiry, intent/action hash va correlation ID.

## 3. False positives va trade-off

- Khong co an toan tuyet doi; can defense-in-depth, least privilege, HITL, audit va emergency stop.
